# python Cybersecurity & network Auditing Tools
welcome to the **python Cybersecurity Tool** repository. thin suite is designed for network reconnaissance, banner grabbing, and web application path discovery-built for practical penetration testing and real-world security audits.

---

## Tools included
1. **port scanners**
   * 'scanner_fast.py':multi-threaded fast port scanner.
   * 'scanner_advanced.py' / 'scanner_service.py': service-aware network scanner.
     
2. **web REconnaissance**

3. **service & vulanerability Analysis**
   *'banner_grabber.py': Extracts service header and version banners from open ports for vulnerability as assessment.
